# 📚 Indeks Dokumentasi Sistem ZAP (Zero Answer Policy)

Koleksi dokumentasi teknis, arsitektur sistem, algoritma penalaran simbolik, desain antarmuka, dan kebijakan operasional platform ZAP.

---

## 🏛️ Arsitektur & Logika Matematika

| Dokumen | Deskripsi |
| :--- | :--- |
| [**ARCHITECTURE.md**](ARCHITECTURE.md) | Spesifikasi arsitektur *Tri-Tier Hybrid Spatial-Symbolic Reasoning* (Client Presentation, API Gateway, Deterministic & Pedagogical Engine) serta diagram data flow. |
| [**ALGORITHM.md**](ALGORITHM.md) | Detail algoritma diagnostik kognitif, modul `backend/cfl` (parser, classifier, counter-example, guardrail), sanitasi AST, mitigasi DoS, dan batas eksponen. |
| [**DESIGN_SYSTEM.md**](DESIGN_SYSTEM.md) | Panduan desain antarmuka, filosofi *Spatial Cognitive Scaffolding*, palet warna (epistemic amber), dan spesifikasi Dual-Mode (Proyektor Gantung vs Smart Board IFP). |

## ⚙️ Backend, Data & Privasi

| Dokumen | Deskripsi |
| :--- | :--- |
| [**BACKEND_SYSTEM.md**](BACKEND_SYSTEM.md) | Panduan sistem backend platform ZAP (`backend/zapcore`), autentikasi Google SSO terverifikasi server, manajemen vault token terenkripsi AES-256-GCM, dan multi-provider AI gateway. |
| [**DATA_AND_LEARNING_POLICY.md**](DATA_AND_LEARNING_POLICY.md) | Kebijakan kurasi basis pengetahuan mandiri (*self-learning flywheel*), filter PII, sanitasi NIK/Email, dan aturan persetujuan pengguna (*explicit opt-in consent*). |
| [**PRIVACY_POLICY.md**](PRIVACY_POLICY.md) | Kebijakan privasi resmi untuk pengguna platform ZAP, retensi data percakapan, hak ekspor (*GDPR-style export*), dan penghapusan data mandiri. |

| [**DEPLOYMENT_GUIDE.md**](DEPLOYMENT_GUIDE.md) | Panduan deployment produksi, konfigurasi container Docker, reverse proxy, SSL, dan manajemen environment. |
